Студент, разработчик и исследователь. Учебные достижения, проекты, научные работы
и инженерное портфолио.

## Быстрый старт

Сайт — статические файлы в корне репозитория:

- `index.html` — разметка и весь контент;
- `styles.css` — оформление;
- `script.js` — темы, мобильное меню, анимации;
- `assets/favicon.svg` — иконка сайта.

Для локального просмотра:

```bash
python3 -m http.server 8000
```

Затем откройте <http://localhost:8000>.

## Публикация на GitHub Pages

1. Загрузите репозиторий на GitHub под именем `portfolio` (или любое другое).
2. Откройте **Settings → Pages**.
3. В разделе **Build and deployment** выберите **Deploy from a branch**.
4. Выберите ветку `main` и папку `/ (root)`, нажмите **Save**.

Сайт станет доступен по адресу:

```
https://<username>.github.io/portfolio/
```

## Как заполнить контентом

Откройте `index.html` и замените:

- текстовые блоки в «Обо мне»;
- теги и описания в «Навыки»;
- карточки проектов в «Проекты» (`<article>` внутри `.projects-grid`);
- пункты в «Наука» (`<li>` внутри `.research-list`);
- события в «Достижения» (`<div>` внутри `.timeline`);
- ссылки и контакты в «Контактах».

Все блоки наглядно подписаны комментариями `<!-- ... -->`.

## Опции

- **Светлая/тёмная тема** — переключатель в правом верхнем углу (запоминается).
- **Анимации** — плавное появление секций при прокрутке (отключаются при
  `prefers-reduced-motion`).
